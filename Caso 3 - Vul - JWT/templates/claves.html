3 Línea para agregar al header del JWT

En Burp (JWT Editor), agregá esta línea al header del token. Es lo que hace que el servidor se baje la clave del atacante:

El header del token queda, por ejemplo:
{ "alg": "RS256", "typ": "JWT", "jku": "{{ jku }}", "kid": "{{ kid }}" }
